JavaScript Events

An event is an action that occurs in the browser, such as when a user clicks a button, submits a form, or hovers over an element. JavaScript can be used to respond to these events and create interactive web pages.

Common JavaScript Events

  • click: Triggered when an element is clicked.
  • mouseover: Triggered when the mouse pointer is moved over an element.
  • mouseout: Triggered when the mouse pointer is moved out of an element.
  • keydown: Triggered when a key is pressed down.
  • keyup: Triggered when a key is released.
  • submit: Triggered when a form is submitted.
